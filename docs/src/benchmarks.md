# Benchmarks

Here are some benchmark timings for tensors in 3 dimensions. For comparison
the timings for the same operations using standard Julia `Array`s are also
presented.

In the table below, `a` denotes a vector, `A`, `As` denotes second order
non-symmetric and symmetric tensors and `AA`, `AAs` denotes fourth order
non-symmetric and symmetric tensors respectively.

| Operation  | `Tensor` | `Array` | speed-up |
|:-----------|---------:|--------:|---------:|
| **Single contraction** | | | |
| `a ⋅ a` | 1.500 ns | 4.125 ns | ×2.8 |
| `A ⋅ a` | 1.708 ns | 24.305 ns | ×14.2 |
| `A ⋅ A` | 1.916 ns | 20.019 ns | ×10.4 |
| `As ⋅ As` | 2.166 ns | 19.664 ns | ×9.1 |
| **Double contraction** | | | |
| `A ⊡ A` | 1.708 ns | 5.458 ns | ×3.2 |
| `As ⊡ As` | 1.708 ns | 5.458 ns | ×3.2 |
| `AA ⊡ A` | 4.333 ns | 48.112 ns | ×11.1 |
| `AA ⊡ AA` | 51.632 ns | 104.189 ns | ×2.0 |
| `AAs ⊡ AAs` | 9.333 ns | 104.411 ns | ×11.2 |
| `As ⊡ AAs ⊡ As` | 3.500 ns | 51.123 ns | ×14.6 |
| **Outer product** | | | |
| `a ⊗ a` | 1.708 ns | 11.177 ns | ×6.5 |
| `A ⊗ A` | 5.833 ns | 20.019 ns | ×3.4 |
| `As ⊗ As` | 2.500 ns | 20.291 ns | ×8.1 |
| **Other operations** | | | |
| `det(A)` | 1.708 ns | 65.459 ns | ×38.3 |
| `det(As)` | 1.708 ns | 65.968 ns | ×38.6 |
| `inv(A)` | 2.375 ns | 186.760 ns | ×78.6 |
| `inv(As)` | 1.916 ns | 186.716 ns | ×97.5 |
| `norm(a)` | 1.500 ns | 4.375 ns | ×2.9 |
| `norm(A)` | 1.708 ns | 5.916 ns | ×3.5 |
| `norm(As)` | 1.708 ns | 5.916 ns | ×3.5 |
| `norm(AA)` | 7.041 ns | 53.764 ns | ×7.6 |
| `norm(AAs)` | 3.208 ns | 52.526 ns | ×16.4 |
| `a × a` | 1.708 ns | 7.292 ns | ×4.3 |
